# NextStep · 会话推进协议

> 回一个数字就继续。
> 给 AI 编码助手的一份家规。写进 `AGENTS.md` 一次，之后每次会话都照它走。

[English](README.md) · 简体中文

ZCode、Claude Code、Codex、Cursor，凡是会读 `AGENTS.md` 的都能用。它只是一份文本，没东西可装，不往外发数据，也没有依赖要管。

## 解决什么问题

AI 干完一件事就停了，接下来做什么又得你来想。

团队攒下的脚本和流程，触发词没人记得住。

常见的应对是往提示词里继续堆说明，结果模型反而更不照着做。

## 它做什么

三个机制，写不满 40 行。

一轮活儿收尾时，助手在回复末尾加一行状态栏和最多五个编号的下一步，选项来自当轮真实对话。你回个数字，它接着干，干完再收尾。

能力登记表把编号对到具体能力。说「菜单」看全表，说 `E1` 直接调用。加一个能力只用加一行。

干活中途不出菜单。说「安静」，它就一直安静到这一轮收尾。菜单之外的事永远可以直说，你不想用它就用不着它。

## 和以前比

| 以前 | 现在 |
|------|------|
| AI 干完就沉默，你追问"接下来呢？" | 每轮收尾都带状态栏和编号下一步 |
| "那个部署脚本叫什么来着？" | 你打 `D2`，登记表替你记着 |
| 200 行的提示词文件，模型只读进去一半 | 40 行以内只做导航，细节放在用得到的地方 |

## 收尾长什么样

> **在办** 重构登录模块 ｜ **在途** 等 CI 结果 ｜ **下一闸口** 提交评审
>
> **下一步（回数字即可）：**
> 1. 先看 CI 挂掉的两条用例
> 2. 补登录模块的单元测试
> 3. 其他，直接说事

回个数字它就接着干。想干别的，直接说。

## 安装

单仓库用：把 [`templates/AGENTS.md`](templates/AGENTS.md)（中文会话）或 [`templates/AGENTS.en.md`](templates/AGENTS.en.md)（英文会话）复制到仓库根，命名 `AGENTS.md`。

只给自己用：把同样内容放进用户级指令文件，ZCode 是 `~/.zcode/AGENTS.md`，Claude Code 是 `~/.claude/CLAUDE.md`。注意这会影响所有工作区的所有会话。

目标文件已存在时，把几节合并进去，不要整个覆盖。模板头部写着协议版本；升级已装的模板，就用 `templates/` 里的最新版覆盖对应几节。

也可以交给技能去装：

```bash
npx skills add Xjm-newgiter/nextstep --global
```

> Gitee 镜像在 gitee.com/xujingmeng/nextstep。上面这条命令指向 GitHub，Gitee 用户请克隆后手动复制模板。

## 验证

新开一个会话说「菜单」。助手回出能力表，就是装好了。

然后把 E1 那行示例换成你第一个真实能力。编号分配后不回收，一直让 E1 指着占位符，这个号就白占了。

## 常见问题

**跟 skill、subagent 有什么不一样？**
都不是一回事。skill 是助手按需打开的操作手册，subagent 是派出去干活、自带上下文的分身，NextStep 是每次会话都自动读的家规。三样可以一起用。

**跟 TodoWrite、计划模式这些内置工具呢？**
内置工具在单个回合里承载执行状态，而且得模型想起来用。NextStep 给的是一份长期有效的约定：只要宿主读 `AGENTS.md`，每轮收尾都会带上状态栏和编号下一步，另外还有能力登记表和安静模式。两者叠加，不冲突，原生工具管清单，状态栏照常出。

**菜单会不会很吵？**
有配额管着。菜单只在收尾和闸口出现，文件本身不超过 40 行，说「安静」就关掉，直到这一轮收尾。

**能力登记在哪？**
就写在 `AGENTS.md` 的能力表里，一行一个：编号、你说什么、我做什么、详情在哪。表会把文件撑过 40 行时，把表挪到单独的文件，原地只留分组行和指针。

**技能什么时候不工作？**
按设计，只有安装和升级才唤醒它。协议已装好时不工作（日常说「菜单」、回数字走的是 `AGENTS.md`，不经过技能）；会话在安装前就开着时不工作；同名技能在更高优先级的路径上把它挡住时不工作；在客户端设置里被关掉时不工作；请求内容跟它的描述对不上时（比如修 bug、写代码）不工作；frontmatter 解析失败时也不工作。技能不工作，不等于协议失效。

**怎么关掉或者卸掉？**
说「停止协议」，状态栏立刻停发，直到你要它恢复。想彻底删掉，把 `AGENTS.md` 里 NextStep 的三节删去即可：推进纪律、能力菜单、硬规则。安装技能想删就在客户端技能设置里卸载，或者直接删它的目录。它本来就是纯文本，删起来很容易。

**说了「菜单」没反应。**
按顺序查这几条。装完之后重开会话了吗；`AGENTS.md` 里真有推进纪律那一节吗；宿主读的是不是你改的那个路径下的 `AGENTS.md`；如果是合并进已有文件，能力表还完整吗；模板头部没有协议版本行的话，说明装的是早期版本，用最新模板刷新一次。

**协议正文有英文版吗？**
暂时没有。完整正文（`会话推进协议.md`）只有中文。两份模板各自语言自足，所以只影响翻阅参考。
